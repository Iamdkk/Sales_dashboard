# 📊 Sales Dashboard - Power BI Project

This Power BI project visualizes and analyzes sales data to provide insights into overall business performance. It includes key KPIs, regional breakdowns, shipping modes, and monthly sales trends to support data-driven decision-making.

## 📁 Files Included

- `sales_dashboard.pbix` – Power BI dashboard file (interactive)
- `sales_dashboard.pdf` – Static snapshot of the dashboard

## 📌 Dashboard Overview

The dashboard covers:

- Total Sales, Orders, Customers, and Products
- Sales by Region (West, East, Central, South)
- Sales by Shipping Mode (Standard, Second Class, First Class, Same Day)
- Monthly Sales Trends
- Top-Selling Products

## 📈 Key Insights

1. **Top Performing Region**: The **West** region leads with **$0.71M** in total sales, followed closely by the East region.
2. **Popular Shipping Mode**: **Standard Class** accounts for the majority of sales (**59.29%**), indicating customer preference for cost-effective delivery.
3. **Seasonal Peaks**: **March and April** show the highest sales months with **$0.35M** and **$0.32M** respectively.
4. **High Sales Volume**: The business processed **9.8K orders** and served **793 customers**, generating **$2.26M** in total revenue.

## 🧩 Filters Available

- Category, Sub-Category, City, State
- Order Date (Year, Quarter, Month)
